Thème 4 · Programme de SNT

Données structurées & formats, organiser pour mieux traiter

Un tableur, une base de données, une API : derrière chaque service se cachent des données organisées. CSV, JSON, descripteurs — les formats qui font tourner l'information.

Frise chronologiqueDe la fiche cartonnée au « big data ».

1970

Le modèle relationnel

Edgar F. Codd (IBM) propose de ranger les données dans des tableaux (lignes × colonnes) reliés entre eux : les bases de données modernes sont nées.

1979

VisiCalc, premier tableur

La feuille de calcul électronique lance la révolution du calcul sur ordinateur personnel.

1985

Microsoft Excel

La feuille de calcul se généralise au grand public et dans toutes les entreprises.

1998

XML standardisé

Le W3C recommande XML : un format universel pour échanger des données structurées entre machines différentes.

2000 → 2010

JSON et open data

JSON s'impose dans les API web ; l'open data ouvre les données publiques (data.gouv.fr en France).

2010

Le « big data »

Traiter des volumes gigantesques de données (mégadonnées) devient un enjeu industriel et scientifique majeur.

2018

Le RGPD encadre les données

En Europe, les données personnelles sont protégées par la loi : consentement, accès, effacement.
