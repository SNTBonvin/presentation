Le Web, des pages reliées entre elles

Quand tu ouvres une page, ton navigateur échange avec un serveur à l'autre bout du monde en quelques millisecondes. HTTP, HTML, URL : les trois inventions qui ont créé le Web.

Frise chronologiqueDu document hypertexte au milliard de sites, de 1989 à aujourd'hui.

1989

Une proposition au CERN

Tim Berners-Lee, chercheur au CERN, propose un système de « gestion de l'information » : des documents reliés entre eux par des liens hypertexte.

1990

HTTP, HTML, URL — et la première page

Il crée le premier navigateur (WorldWideWeb), le premier serveur web et la toute première page web : info.cern.ch. Trois inventions d'un coup.

1993

Mosaic : le Web en images

Premier navigateur graphique grand public avec images intégrées : le Web explose hors des universités.

1994

Le W3C standardise le Web

Fondation du consortium qui définit les langages du Web (HTML, CSS…) pour qu'ils fonctionnent partout, de la même façon.

1995

JavaScript : les pages vivent

Créé en 10 jours par Brendan Eich chez Netscape, JavaScript rend les pages interactives.

1998

Google : la porte d'entrée du Web

Face à un Web devenu immense, le moteur de recherche devient le point de départ de toute navigation.

2004

Le « Web 2.0 »

Les internautes produisent le contenu : Wikipédia, blogs, réseaux sociaux. Lire ne suffit plus, chacun publie.

2010

HTML5 et le Web mobile

Le navigateur rivalise avec les applications natives : le Web devient la plateforme universelle.
